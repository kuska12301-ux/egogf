# Егор — играй вместе

Мобильное приложение с профилями, входом и многопользовательскими играми. Работает на Node.js без внешних npm-зависимостей и подходит для BotHost.

## Возможности

- Регистрация по уникальному логину, имени в игре и паролю.
- Вход и выход из профиля; пароль хранится как соль + scrypt-хеш.
- Крестики-нолики 1 на 1: создание открытого лобби, вход второго игрока, очередь ходов и проверка победы на сервере.
- Кодовый замок: совместная игра до 4 участников, 8 общих попыток и подсказки «на месте» / «рядом».
- Состояния комнат хранятся в data/app-data.json; браузеры обновляют партии каждые 1,8 секунды.
- Предыдущая версия мини-игр доступна на /classic.html.

## Запуск

    npm start

Сервер слушает 0.0.0.0 и порт из PORT (по умолчанию 3000). Данные профилей, игр и лобби сохраняются в DATA_DIR, если он задан, иначе в ./data рядом с приложением. Для BotHost каталог данных должен оставаться на постоянном диске сервиса.

## Профили

Логины принимают 3–20 строчных латинских букв, цифр или _. Пароль должен быть длиной 8–72 символа. Сессии используют HttpOnly cookie и автоматически включают флаг Secure за HTTPS-прокси.
